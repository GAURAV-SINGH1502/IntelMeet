# IntellMeet

AI-Powered Enterprise Meeting & Collaboration Platform

## Features

### Authentication

* User Signup
* User Login
* JWT Authentication
* Protected Routes
* Password Hashing with bcrypt

### Profile Management

* Avatar Upload using Cloudinary

### Meeting Management

* Create Meeting
* Update Meeting
* Delete Meeting
* List Meetings

### Real-Time Features

* Socket.IO Integration
* Meeting Rooms
* Real-Time Chat
* Notifications

### Video Calling

* WebRTC Peer Connection
* Local Video Stream
* Remote Video Stream
* ICE Candidate Exchange

### Caching

* Redis Integration
* Meeting Cache
* Cache Invalidation

## Tech Stack

### Frontend

* React
* Vite
* Socket.IO Client

### Backend

* Node.js
* Express.js
* MongoDB
* Mongoose
* Redis
* Socket.IO

### Storage

* Cloudinary

## Installation

### Backend

```bash
cd server
npm install
npm run dev
```

### Frontend

```bash
cd client
npm install
npm run dev
```

## Environment Variables

Backend `.env`

```env
PORT=5000
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_secret
CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_key
CLOUDINARY_API_SECRET=your_secret
```
